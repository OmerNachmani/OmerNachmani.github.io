A timing side-channel demonstration

A small Arduino and Python project illustrating how an early-exit comparison can reveal information through response time.

Omer Nachmani · SimpleTimingSCA · Source available

Overview

SimpleTimingSCA is a teaching demonstration built around a four-character PIN check on an Arduino. The comparison exits at the first mismatch, and a deliberate per-character delay makes the timing difference easy to observe.

A Python host script measures responses over USB serial. The project demonstrates the connection between a control-flow decision in code and information visible outside the device.

Implementation

Device
Arduino PIN-checking sketch
Host
Python measurement script using serial communication
Observed behavior
A longer matching prefix takes longer to reject
Context
An intentionally amplified timing leak for demonstration
