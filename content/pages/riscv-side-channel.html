Power side-channel analysis on RISC-V

Studying the power leakage of software AES-128 running on a processor implemented on FPGA.

Omer Nachmani · B.Sc. final project · Ongoing research

Overview

This project examines power leakage from software AES-128 executed by a PicoRV32 RISC-V processor on a CW305 FPGA. The processor runs the encryption code as software, so the study includes the behavior of the CPU and its surrounding hardware interfaces.

I developed the RTL integration and verification setup to establish a baseline for investigating hardware changes intended to reduce the leakage.

Baseline results

The existing baseline recovered all 16 AES-128 key bytes in two sessions. Ciphertext correctness was checked independently.

The completed work includes processor and hardware-interface integration, RTL development, verification, and the baseline research. I performed the research and implementation completed to date.
