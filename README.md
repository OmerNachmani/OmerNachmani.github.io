# OmerNachmani.github.io

Personal portfolio site based on the **Strongly Typed** template by [HTML5 UP](https://html5up.net/strongly-typed).

## Edit the site

Most content is in:

- `index.html` — text, sections, project links
- `assets/css/custom.css` — portfolio-specific styling
- `assets/css/main.css` — original template styling (usually leave this alone)

Search `index.html` for `TODO` to find the most useful next edits, such as adding LinkedIn/email and a public link for the SCA-MIPS project.

## Preview locally

You can double-click `index.html`, or run a small local server from this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

This repository is intended to be published from the `main` branch, repository root. Put `index.html`, `assets/`, `images/`, and the other files directly at the root of `OmerNachmani.github.io`.

The original HTML5 UP license is preserved in `LICENSE.txt`.
